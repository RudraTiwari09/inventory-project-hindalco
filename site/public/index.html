Not loading on a company network?
  • The app runs on a Python server at __APP_URL__ over HTTPS on port 443 and uses secure WebSockets (wss://). Ask IT to allow that host and WebSocket upgrades through the proxy.
  • On the free hosting tier the server sleeps when idle. The first visit can take up to a minute to wake it.
  • For plant data, the safest option is running it inside the plant intranet with the included Dockerfile.
